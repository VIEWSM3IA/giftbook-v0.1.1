# 礼物簿体验优化验收

目标：围绕具体的 TA 完成「记下 → 回看/修正 → 选礼 → 收藏 → 主动反馈结果」，提供可信的决策信息与明确的私人/公开边界。

约束：保留原生小程序；H5 同步可见流程；业务规则集中于 domain.js；不增加依赖、不接入假后端、不清除已有用户数据。局域网部署只提供本地验收服务。

验收：
- 记录默认不选择反应，支持不喜欢/还不知道；切换 Tab、刷新/重新打开后保留未提交记录。
- 可查看、编辑私人备注和反应；编辑不静默改动已提交的公开快照。
- TA 可编辑称呼、关系、年龄段和标签，未提供的画像不被编造。
- 推荐支持场景/预算筛选、诚实的匹配依据、已送提示、反应和行为证据；无结果可清除筛选或记历史。
- 收藏后可立即反馈结果；已送出不重复生成记录、不再作为待送候选。
- 分享前展示完整匿名快照，提交后显示待审核；有帮助与真实送出统计分开。
- H5 移动端无水平溢出，主要文字可读，表单关联标签，保存结果以完成为主操作。
- npm test、npm run check、H5 核心流程及局域网 HTTP 检查通过；明确微信真机未验证的边界。

设计：保留纸张与玫瑰色基调，缩短装饰性标题；人物卡提供最近送礼摘要，历史采用时间线；反应、证据和收藏状态优先于作者及装饰。
