# 礼物簿 V0.1.1 交付契约

本版以 TA 为横向索引、送礼日期为纵向日志。首页直接打开上次停留的 TA；不存在时打开排序最前的 TA。用户可在顶部横向切换、长按拖动 TA 排序，在右下角一次点击为当前 TA 记礼物。左上角账号入口承接昵称、隐私与数据、关于、退出和注销。没有底部导航及 V0.2 入口。

数据库升级只增加 `recipients.sort_order`、`users.last_active_recipient_id`，原有 TA、标签、礼物和反应不变。首次升级按 V0.1 的创建时间倒序填入 TA 顺序。`PATCH /v1/recipients/order` 必须提交本人全部未删除 TA 的无重复 ID；`PATCH /v1/me/active-recipient` 仅接受本人的未删除 TA。删除 TA 会清除最后停留 ID，客户端回退到排序最前的 TA。

原生小程序与 H5 共用 `miniprogram/utils/domain.js` 的日志格式。日志按送礼日期倒序，同年只显示一次年份，跨年重新显示。编辑与删除收在记录次级操作中；新增表单保留 V0.1 字段及校验。H5 是本机账号验收预览，不替代微信授权。

Native Mobile 优化后，顶部工具栏与 TA Rail 是独立的 UI 层；内容层使用扁平日志和分隔线。新增 TA、礼物以及主页内编辑使用 Sheet；礼物行以左滑显示编辑和删除，长按提供菜单。切换 TA 时立即更新内容，保存上次 TA 在后台进行；排序进入屏幕边缘时自动滚动。上述改动不改变数据库字段或 API 契约。

回退代码时保留 V0.1.1 新增的两列，旧 API 可继续读取既有数据。恢复本版则重新启动预览服务；不要删除数据库或重跑破坏性脚本。
